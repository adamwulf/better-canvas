Pangram API key

The Send to Pangram button in SpeedGrader uses this key. Make a key in your Pangram account. The key is saved only in this browser.

Pangram model

Each check uses this model. Newest asks Pangram at each check which models your key can use, and picks the pangram- model with the highest number.

Saved Pangram results

Each Pangram result is saved in this browser. When you prepare a submission with the same text again, SpeedGrader shows the saved result and sends nothing.
